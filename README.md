# User Management System

A Flask web application for user authentication and CRUD operations with a clean UI.

## Live Demo
https://krishnasrigavini.github.io/User-Management/

## Tech Stack
- **Backend**: Python, Flask
- **Frontend**: HTML, CSS, Jinja2
- **Database**: SQLite

## Features
- User Registration and Login
- Password security with hashing
- Create, Read, Update, Delete users
- Session management
- Responsive UI
